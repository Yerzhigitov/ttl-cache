# ttlcache — LRU-кэш с TTL и async-декоратор

```python
@async_cached(maxsize=1000, ttl=30)
async def exchange_rate(pair: str) -> float: ...
```

## Что внутри
- **LRU на `OrderedDict`**: `get` и `put` за O(1). При переполнении вытесняется давно не используемый ключ.
- **TTL**: записи устаревают по времени, просроченные удаляются при чтении.
- **Защита от cache stampede**: если 100 корутин одновременно запрашивают отсутствующий ключ, во внешний API уходит **один** запрос, остальные ждут его результат.
- Счётчики `hits`/`misses` для метрик.

```bash
python3 ttlcache.py        # демо: 100 параллельных вызовов → 1 запрос
python3 -m unittest -v
```
